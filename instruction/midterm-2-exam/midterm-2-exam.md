# Midterm 2 Exam
  
This exam will be taken in the testing center. It will be available starting at 8:00 am on Thursday, October 29th. It must be started by 9:00 pm on Tuesday, November 3rd. The testing center will charge a late fee for any exam taken on November 3rd.

There is no time limit for the exam, but you should give yourself two to three hours to complete the exam.

The exam covers the second third of the course, from Code Reuse through API Gateway. See [MIDTERM 2 - Preparation Help](../midterm-2-review/midterm-2-review.md).
